## 📁 Browse Generated Operas

The **`showcase/`** directory contains complete example operas:

```
showcase/
├── hartford_ascending_an_opera_of_love_and_ruins/  # 8 scenes, complete
├── iron_aria_the_lost_city_of_hartford/            # 6 scenes
└── vines_of_hartford_arias_of_steel/               # Full narration
```

Each opera includes:
- Complete libretto (Markdown)
- Scene illustrations (PNG)
- Audio narrations (MP3)
- Critical reviews
- Additional materials (music, podcasts)
